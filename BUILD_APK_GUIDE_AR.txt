دليل تحويل Farah Maritime English and Arabic إلى APK

ملاحظة مهمة:
هذه الحزمة هي مشروع Android قابل للبناء، وليست ملف APK جاهزاً للتثبيت. يلزم تشغيل عملية البناء في Android Studio أو GitHub Actions.

الطريقة الأولى: Android Studio (على كمبيوتر)
1) فك ضغط Farah_Maritime_Android_Complete_Project.zip.
2) افتح Android Studio واختر Open ثم اختر مجلد FarahMaritimeAndroid.
3) انتظر Gradle Sync. إذا طُلب تثبيت Android SDK Platform 35 فوافق على التثبيت.
4) من القائمة اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5) بعد نجاح البناء سيظهر رابط Locate. ملف APK التجريبي يوجد عادةً هنا:
   app/build/outputs/apk/debug/app-debug.apk
6) انقل الملف إلى هاتف Android وافتحه للتثبيت. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

الطريقة الثانية: البناء التلقائي عبر GitHub (يمكن متابعة النتائج من الهاتف)
1) سجّل الدخول إلى GitHub وأنشئ مستودعاً جديداً (New repository).
2) ارفع محتويات مجلد FarahMaritimeAndroid إلى المستودع، مع الحفاظ على المجلد .github/workflows.
3) افتح تبويب Actions في المستودع.
4) اختر Build Farah Maritime APK ثم Run workflow.
5) انتظر حتى تنتهي العملية بنجاح.
6) افتح نتيجة التشغيل، وانزل إلى Artifacts، ثم نزّل Farah-Maritime-debug-APK.zip.
7) فك ضغطه لتحصل على app-debug.apk، ثم انقله إلى الهاتف وثبّته.

ملاحظات:
- الـ APK الناتج من assembleDebug نسخة تجريبية (Debug) للتثبيت والاختبار، وليس إصداراً موقعاً للنشر التجاري.
- لإصدار Release يلزم إنشاء مفتاح توقيع (keystore) وحفظه وكلمات مروره بأمان. لا تشارك هذه البيانات.
- النطق يعتمد على محرك تحويل النص إلى كلام المتوفر في Android؛ قد يلزم تنزيل بيانات اللغة الإنجليزية من إعدادات الهاتف.
- المحتوى التعليمي المضمن يعمل محلياً، ولا يحتاج اتصالاً بالإنترنت بعد تثبيت التطبيق.
- اختبر التطبيق على جهازك قبل استخدامه في التدريب العملي. لا تستبدل إجراءات السلامة وتعليمات الضابط المسؤول بالمحتوى التعليمي.
