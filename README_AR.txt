Farah Maritime English and Arabic
=================================

هذه نسخة تطويرية من مشروع تطبيق أندرويد لتعليم الإنجليزية البحرية بالعربية والإنجليزية.

المحتويات الحالية:
- 18 وحدة تعليمية للسفن، وخصوصاً سفن البضائع العامة وطاقم السطح.
- قاموس ثنائي اللغة مع بحث باللغة العربية أو الإنجليزية.
- نطق المصطلحات الإنجليزية باستخدام خدمة Text-to-Speech الموجودة في Android.
- رسم تفاعلي مبسط لأجزاء السفينة.
- اختبارات قصيرة مع احتساب النقاط.
- حفظ الدروس المكتملة والكلمات المفضلة والنقاط محلياً على الجهاز.
- الدروس والواجهة مدمجة داخل assets؛ لا يلزم اتصال بالإنترنت لتصفح المحتوى.

طريقة إنشاء APK:
1. ثبّت Android Studio على كمبيوتر يعمل بنظام Windows أو macOS أو Linux.
2. افتح المجلد FarahMaritimeAndroid بواسطة Android Studio (Open project).
3. اسمح لبرنامج Android Studio بتنزيل Android Gradle Plugin وAndroid SDK المطلوبين عند الطلب.
4. من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5. بعد اكتمال البناء، استخدم رابط Locate الذي يظهر في Android Studio للوصول إلى ملف app-debug.apk.
6. انقل APK إلى هاتف Android، وافتحه واسمح بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.

متطلبات البناء المضبوطة بالمشروع:
- Android Gradle Plugin 8.7.3
- Gradle 8.9 أو إصدار متوافق مع Android Gradle Plugin
- Android SDK Platform 35
- Minimum Android API 23 (Android 6.0)

ملاحظات مهمة:
- هذا مشروع مصدر Android وليس ملف APK جاهزاً للتثبيت.
- يجب إجراء البناء والتجربة على جهاز Android فعلي قبل النشر.
- ميزة النطق تستخدم أصوات Android المثبتة على الهاتف؛ قد يلزم تنزيل بيانات صوت اللغة الإنجليزية من إعدادات تحويل النص إلى كلام.
- محتوى الدروس توعوي للمبتدئين، ولا يحل محل SMS أو تعليمات الربان أو الضابط المسؤول أو كتيبات الشركة المصنعة.
- لا تعتمد على أي درس في عمليات الرفع أو الربط أو دخول الأماكن المغلقة أو أعمال التنظيف دون تصريح وتقييم مخاطر وإشراف مختص.


بناء تلقائي اختياري عبر GitHub Actions:
- يوجد ملف إعداد داخل .github/workflows/build-apk.yml.
- ارفع مجلد المشروع إلى مستودع GitHub باسم main أو master.
- افتح تبويب Actions وشغّل Build Farah Maritime APK.
- بعد نجاح المهمة، نزّل Artifact باسم Farah-Maritime-debug-APK.
- هذا ملف Debug للتجربة؛ للنشر العام أنشئ نسخة Release موقعة بمفتاحك الخاص.
