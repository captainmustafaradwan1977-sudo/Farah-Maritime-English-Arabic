# RADWAN MARINE STORES FINDER

تطبيق Android مستقل ثنائي اللغة (العربية والإنجليزية) للبحث في مستلزمات السفن وإنشاء طلبات المخازن دون اتصال بالإنترنت.

## الوظائف
- البحث محلياً باسم الصنف أو وصفه أو رقم IMPA / ISSA.
- قاعدة بيانات أولية لأصناف بحرية شائعة، مع تمييز واضح بأن أكوادها غير متحققة حتى استيراد بيانات مرخصة.
- استيراد ملفات CSV المصرح باستخدامها، وتخزينها محلياً على الهاتف.
- إضافة أصناف خاصة بالمستخدم.
- إنشاء طلب مخازن، حفظه محلياً، وتصديره CSV إلى مجلد Downloads/Radwan Marine.
- لا يحتاج البحث أو إعداد الطلبات إلى اتصال بالإنترنت.

## صيغة CSV للاستيراد
يجب أن يحتوي الملف على عناوين الأعمدة التالية:
`name_en,name_ar,impa,issa,category,unit,description`
يمكن ترك عمود IMPA أو ISSA فارغاً إذا لم يتوفر الرمز.

## بناء APK
يتم البناء عبر GitHub Actions باستخدام ملف:
`.github/workflows/build-radwan-apk.yml`
اسم الـ artifact: `RADWAN-MARINE-STORES-FINDER-APK`

## حقوق البيانات
لا يتضمن التطبيق نسخاً غير مرخصة من بيانات IMPA أو ISSA. يجب استيراد ملفات البيانات التي يملك المستخدم حق استخدامها وفق شروط الترخيص. أكواد الأصناف الأولية غير معبأة لتجنب تقديم أرقام غير مؤكدة.
